# VDK Net Limiter Pro v2.1

Ứng dụng Android (không cần Root) giúp theo dõi thiết bị đang kết nối vào Hotspot 4G, xem tốc độ realtime, tên miền truy cập gần nhất, **chọn bóp băng thông riêng cho từng thiết bị (chuẩn từng KB/s)** hoặc **chặn mạng ngay lập tức**.

*Code By VDK • @Developeronetop*

## Cách build ra file `.apk` trên GitHub Actions
1. Giải nén file `VDK-Net-Limiter-Pro-v2.1-FIXED.zip`.
2. Đẩy toàn bộ nội dung bên trong thư mục `VDK-Net-Limiter-Pro/` lên repo GitHub của bạn (ghi đè toàn bộ bản cũ).
3. Vào tab **Actions** -> chờ workflow **Build VDK Net Limiter Pro APK** chạy xong tích xanh -> tải file `VDK-Net-Limiter-Pro-v2.1.apk` ở mục **Artifacts**.
